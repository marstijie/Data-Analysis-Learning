二分类（以0，1为例）  
* 真正率，简称TPR。表示实际为1中，被预测为1所占的比例。
* 假正率，简称FPR。 表示实际为0中，被预测为0所占的比例。
* ROC曲线：衡量二分类模型性能的曲线  
   横轴：假正率（误报率）FPR - 负样本中被错判为正的比例  
   纵轴：真正率（召回率）TPR - 正样本中被正确识别的比例  
* AUC值：ROC曲线下的面积  
0.5：模型无区分能力（相当于随机猜）  
0.7-0.8：有一定区分能力  
0.8-0.9：区分能力良好  
0.9-1.0：区分能力优秀  
1.0：完美模型（实际中几乎不存在）  
* K折交叉验证：将数据均分为K份，每次选取1份作为验证集，剩下K-1份做为交叉验证的训练集。  
经过K次交叉验证，得到的K次测试效果，计算K次效果的均值能更准确的评估模型
* GridSearch网格搜索是一种穷举搜索的参数调优手段：  
自动遍历所有候选参数，循环建立模型并评估模型，选取最好的参数作为最终结果。
